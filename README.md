# l-hopkins-site

Athlete site for L Hopkins. Built with Vite, three.js and GSAP; deployed to GitHub Pages on every push to `main`.

**New to this project?** Start with [`docs/HANDOVER.md`](docs/HANDOVER.md). Decisions, approvals and assets are tracked in Notion: https://app.notion.com/p/3ff0ca41bc738177b59cf0471151b02a

```bash
npm install
npm run dev     # local dev server
npm run build   # production build into dist/
```
